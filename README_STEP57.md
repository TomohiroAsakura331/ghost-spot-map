## 必要なライブラリ
追加なし（`streamlit` のみ。pandas・numpy・altair は streamlit と一緒に入ります）。`requirements.txt` は作っていません。

## 内容
- E56 は STEP 5.6 のモデルD（トンネル・橋だけの掲載区画を学習から外したモデル）による環境要因の評価値で、値は再計算せず転記しています。
- 心霊スポットの掲載傾向に関連する環境要因の評価であり、心霊現象の実在・心霊体験の起こりやすさ・霊の強さではありません。3D の高さも同じで、実際の標高ではありません。
- ページ内の表示（サイドバー「E56 の表示」）：1. 研究概要、2. 2Dスコアマップ、3. 3Dスコアマップ、4. スポット・候補の詳細分析。
  URL に `?view=3` を付けると 3D 表示から開きます。
